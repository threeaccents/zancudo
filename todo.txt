Next steps

1. Build the topic trie (src/mqtt/TopicTrie.zig or src/TopicTrie.zig)
   - Node: children keyed by level (std.StringHashMapUnmanaged(*Node)),
     plus the subscribers whose filter ends at that node.
   - subscribe(filter, client, qos): walk/create nodes, add the subscriber,
     or replace its QoS if the client is already there.
   - match(topic): follow exact, "+" and "#" children, collect subscribers.
   - removeClient(client): remove the client everywhere and prune empty
     nodes. Client keeps a list of its filters so this can find them.
   - The trie owns its nodes and level strings, so it needs deinit.
   - Filter rules: "#" only as the whole last level, "+" only as a whole
     level. Topics starting with "$" don't match "#" or "+" at the first
     level. Empty levels ("a//b") are real levels.

2. Finish SUBSCRIBE
   - Fix handleSubscribe in Broker.zig: the stray "." in
     "try .self.handleSubscribe", and pass a buffer to decode:
     var topic_buf: [32]Subscribe.Topic = undefined;
     const sub = try Subscribe.decode(body, &topic_buf);
   - Give Broker an allocator field (alloc: Allocator), set in main.
   - Add each topic to the trie for the client, granted QoS 0.
   - Call broker.removeClient(c) in closeClient before destroying the
     Client, so the trie never holds a dangling pointer.
   - Reply with SUBACK: 0x90, remaining length (2 + number of topics),
     the packet ID, then one 0x00 per topic in the same order.
